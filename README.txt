THE SEVENTH SILENCE — PILOT CHAPTER

DEPLOYMENT
Upload the contents of this folder to any static web host.
index.html is the entry point. No build process, server runtime, or external dependency is required.

STRUCTURE
index.html          Reader and access-gate markup
css/style.css       Mobile-first visual design
js/app.js           Access, loading, progress, page detection, and scroll restoration
assets/pages/       Original cover, separator, and manga pages 01–40

ACCESS NOTE
The password gate is implemented entirely in the browser for casual/private access control. Client-side protection cannot provide strong security because a knowledgeable visitor can inspect downloaded site files and assets. Use server-side authentication or host-level access control if stronger protection is required.
